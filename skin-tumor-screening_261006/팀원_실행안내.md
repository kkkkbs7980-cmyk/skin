# 3분류 실험 실행 안내 (팀원용)

정상(점) / 양성 / 악성 3분류로 실험 10개를 차례로 돌립니다. 버튼 한 번이면 끝까지 알아서 돕니다.

## 1. 파일 덮어쓰기
- 받은 zip 을 **지난번 프로젝트 폴더**(`src`, `data` 가 있는 폴더)에 풀어서 덮어쓰기.
- `data/` 폴더는 그대로 둡니다. 지난번 7종 결과(`outputs/`)도 건드리지 않습니다. 새 결과는 `outputs_3cls/` 에 따로 생깁니다.

## 2. 실행
1. **Anaconda Prompt** 를 엽니다. (탐색기에서 bat 파일을 그냥 더블클릭하면 conda 환경이 안 켜져서 오류가 납니다.)
2. 지난번에 쓰던 환경을 켭니다: `conda activate (지난번 환경 이름)`
3. 프로젝트 폴더로 이동: `cd (프로젝트 폴더 경로)`
4. 실행: `run_all.bat`

## 3. 정상인지 확인
- 처음에 `사진 축소 캐시` 진행 막대가 지나갑니다 (사진 5,310장을 작게 줄여 두는 단계, 몇 분).
- 그다음 `[1/10] 00_baseline` 이 뜨고 `학습` 진행 막대가 움직이면 **정상**입니다.
- epoch 하나가 끝날 때마다 `[1/20] ... 40초 (누적 0.7분)` 처럼 시간이 찍힙니다.
  **첫 epoch 시간 × 20 × 10** 이 전체 예상 시간입니다.
- 빨간 오류 문구(`Error`, `Traceback`)가 나오면 **화면을 그대로 캡처해서** 보내 주세요.
  한 실험이 실패해도 다음 실험은 자동으로 이어서 돕니다.

## 4. 미팅 50분 전
- 새로 따로 시작하는 건 하지 말고, 지금 돌고 있는 실험은 **끝까지 둡니다. 창은 닫지 마세요.**
- 실험 하나가 끝날 때마다 결과표가 자동으로 갱신되므로, 그 시점까지 끝난 실험은 전부 표에 들어가 있습니다.

## 5. 미팅에 가져갈 것
- `outputs_3cls/결과표.md` 를 열어서 가져갑니다.
  실험마다 설정 한 줄 + 표(recall, precision, F1, AUC, accuracy)가 있고, 괄호는 원본 대비 증가폭입니다.
- 실험별 혼동행렬 그림은 `outputs_3cls/<실험이름>/confusion_matrix.png` (보고서용).

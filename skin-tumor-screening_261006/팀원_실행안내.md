# 3차 실험 실행 안내 (팀원용, 10/20)

이번에는 모델을 **ConvNeXt-Tiny** 로 바꾸고 **50 epoch** 씩 실험 8개를 돌립니다. 버튼 한 번이면 끝까지 알아서 돕니다.
**예상 시간: 약 2.5–3시간.**

## 1. 파일 덮어쓰기
- 받은 zip 을 **지난번 프로젝트 폴더**(`src`, `data` 가 있는 폴더)에 풀어서 덮어쓰기.
- `data/` 폴더는 그대로 둡니다. 2차 결과(`outputs_3cls/`)도 건드리지 않습니다. **새 결과는 `outputs_3cls_v3/`** 에 따로 생깁니다.

## 2. 실행 전 확인
- **인터넷 연결 필요**: 처음 실행할 때 ConvNeXt 가중치(약 110MB)를 내려받습니다.

## 3. 실행
1. **Anaconda Prompt** 를 엽니다. (탐색기에서 bat 파일을 그냥 더블클릭하면 conda 환경이 안 켜져서 오류가 납니다.)
2. 지난번에 쓰던 환경을 켭니다: `conda activate (지난번 환경 이름)`
3. 프로젝트 폴더로 이동: `cd (프로젝트 폴더 경로)`
4. 실행: `run_all.bat`

## 4. 정상인지 확인
- 맨 처음 **연습 실행(`[smoke]`, 1 epoch, 1–2분)** 이 돕니다. 여기서 오류가 나면 본 실험은 시작하지 않고 멈춥니다.
  → 화면을 캡처해서 보내 주세요.
- `Practice run OK. Starting main experiments.` 가 뜨고 `[1/8] 00_baseline` 이 시작되면 **정상**입니다.
- 시작할 때 `모델: ConvNeXt-Tiny / AdamW ... 배치 16, AMP bf16` 줄이 보여야 합니다. `fp32` 로 나오면 캡처해서 알려 주세요 (돌아가긴 하지만 느림).
- epoch 하나가 끝날 때마다 `[1/50] ... 20초 (누적 0.3분)` 처럼 시간이 찍힙니다.
- 빨간 오류 문구(`Error`, `Traceback`)가 나오면 **화면을 그대로 캡처해서** 보내 주세요.
  한 실험이 실패해도 다음 실험은 자동으로 이어서 돕니다.

## 5. 미팅 50분 전
- 새로 따로 시작하는 건 하지 말고, 지금 돌고 있는 실험은 **끝까지 둡니다. 창은 닫지 마세요.**
- 실험 하나가 끝날 때마다 결과표가 자동으로 갱신되므로, 그 시점까지 끝난 실험은 전부 표에 들어가 있습니다.

## 6. 미팅에 가져갈 것
- `outputs_3cls_v3/결과표.md` 를 열어서 가져갑니다.
  실험마다 "설정:" 줄(모델 / 증강 / epoch / 학습 설정) + 표(recall, precision, F1, AUC, accuracy)가 있고, 괄호는 원본 대비 증가폭입니다.
  맨 끝에 ResNet50 vs ConvNeXt 모델 비교표가 있습니다.
- 실험별 혼동행렬 그림은 `outputs_3cls_v3/<실험이름>/confusion_matrix.png` (보고서용).

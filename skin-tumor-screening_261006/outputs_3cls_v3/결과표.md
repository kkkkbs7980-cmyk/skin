# 3분류(정상/양성/악성) 실험 결과

test 1059장 기준 (병변 단위 분할). 숫자는 %. 괄호 = 원본(00_baseline) 대비 증가폭(%p).

- 클래스별 accuracy 는 '그 클래스인가 아닌가'의 2진 정확도((TP+TN)/전체)라 쉬운 음성 사진까지 맞힌 걸로 세어 전체 accuracy 보다 높음.
- 전체 행: recall·precision·F1·AUC 는 3클래스 단순 평균(macro), accuracy 는 전체 정확도. 전체 recall(= 클래스별 recall 평균)이 곧 balanced accuracy.
